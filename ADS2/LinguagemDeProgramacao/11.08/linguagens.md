 # LINGUAGENS DE PROGRAMAÇÃO
Cada linguagem foi pensada para solucionar um problema específico.

Temos linguagens **ESTÁTICAS** e **DINÂMICAS**, a linguagem estática verifica a tipagem antes de rodar o código, impedindo com que o erro aconteça, já a dinâmica verifica o tipo quando roda, os erros vão aparecer quando o projeto rodar.

Temos também linguagens **FORTEMENTE TIPADAS** e **FRACAMENTE TIPADAS**, todas as linguagens possuem tipos, a diferença é que algumas não convertem tipos sozinha, ou seja, você tem que declarar o tipo de uma variável, outras (fracamente tipadas), convertem tipos sozinhas, isso pode ser perigoso e ocasionar erros.

### COMPILADOR
Um compilador é um programa que transforma código escrito por um programador em outra representação que possa ser executada ou processada posteriormente.

1. Código que você escreve
2. Compilador / Interpretador / Runtime
3. Instruções de máquina
4. CPU

O compilador transforma esse código em código de máquina que o computador consegue executar.
linguagens podem ter estratégias diferentes para transformar e executar o código.


### Interpretador
O interpretador recebe o código e executa o programa através de um ambiente de execução, sem exigir que você gere previamente um executável nativo.

### Transpilação
A transpilação transforma uma linguagem em outra linguagem de nível semelhante, normalmente para que a linguagem resultante possa ser executada posteriormente.

## Python
Python é uma linguagem de programação de auto nível, conhecida por sua sintaxe simples e fácil de entender.
Possui tipagem dinâmica e gerenciamento automático de memória, facilitando o desenvolvimento.
É uma linguagem multiparadigma, permitindo programação procedural, orientada a objetos e funcional.
Possui uma grande quantidade de bibliotecas e frameworks para diferentes necessidades.
É utilizada em desenvolvimento web, automação, análise de dados, inteligência artificial e machine learning.
Também é muito utilizada no ensino de programação devido à sua facilidade de aprendizado.
