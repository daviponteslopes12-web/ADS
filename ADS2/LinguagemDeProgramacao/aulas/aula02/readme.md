# Aula 02 — Tipos, expressões e estruturas de controle

## Tópicos abordados

* Tipos de dados em TypeScript.
* Variáveis e constantes.
* Operadores e expressões.
* Estruturas de seleção: `if`, `else` e `switch`.
* Estruturas de repetição: `for`, `while` e `do while`.
* Conversão de programas em C para TypeScript.

## Tecnologias e ferramentas

* TypeScript
* Node.js
* VS Code

## Objetivo

Aprender como os conceitos de lógica de programação são utilizados em TypeScript e praticar a conversão de programas próprios.
