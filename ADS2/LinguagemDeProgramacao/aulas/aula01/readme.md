# Aula 01 — Git, TypeScript e ambiente

## Tópicos abordados

* Introdução ao TypeScript.
* Diferenças entre JavaScript e TypeScript.
* Configuração do ambiente de desenvolvimento.
* Git e GitHub.
* Leitura de código em C.
* Previsão da saída de programas.
* Diagnóstico dos conhecimentos de programação.

## Tecnologias e ferramentas

* TypeScript
* Node.js
* VS Code
* Git
* GitHub

## Objetivo

Preparar o ambiente e entender a proposta da disciplina, revisando lógica de programação e conhecendo o TypeScript.
