# Aula 03 — Funções, escopo e módulos

## Tópicos abordados

* Criação e utilização de funções.
* Parâmetros e retorno de valores.
* Escopo de variáveis.
* Passagem de parâmetros por valor e referência.
* Modularização de programas.
* Importação e exportação de módulos.

## Tecnologias e ferramentas

* TypeScript
* Node.js
* VS Code

## Objetivo

Aprender a organizar o código em funções e módulos, facilitando a reutilização e manutenção dos programas.
