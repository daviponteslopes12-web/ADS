1. npm init --y -> Cria estrutura básica de um projeto Node e controla dependências e scripts.


2. npm i -D typescript -> Verificar tipos e compilar ts para js.

3. npm i -D tsx -> Executar ts durante desenvolvimento, sem precisar compilar manualmente.

4. npm i -D @types/node -> Fornece para o TypeScript, os tipos das APIs do Node, faz ele entender funcionalidades do Node.


5. npx tsc --init -> Cria o arquivo tsconfig, que define como o ts deve tratar e compilar seu projeto.

6. npx tsc index.ts -> comando para compilar projeto!
