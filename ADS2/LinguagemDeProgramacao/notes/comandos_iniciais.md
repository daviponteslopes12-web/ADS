### npm init --y 
- Cria estrutura básica de um projeto Node e controla dependências e scripts.

---

### npm i -D typescript 
- Verificar tipos e compilar ts para js.

### npm i -D tsx 
- Executar ts durante desenvolvimento, sem precisar compilar manualmente.

### npm i -D @types/node 
- Node não conhece tipos por padrão.

---

### npx tsc --init 
- Cria o arquivo tsconfig, que define como o ts deve tratar e compilar seu projeto.

### npx tsc index.ts 
- comando para compilar projeto!
