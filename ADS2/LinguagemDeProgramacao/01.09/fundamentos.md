# Fundamentos das Linguagens

```
    Linguagens de programação compartilham atributos e fundamentos entre si, habilidades que são necessárias independente da linguagem. Com o avanço da inteligência artificial, o grande problema de desenvolvedores deixou de ser a sintaxe e se tornou a resolução de problemas e arquitetar o sistema.
```
---
### Sintaxe compartilhada em diversas linguagens:

- Variáveis
- Constantes
- Operadores e expressões
- Laço de repetição
- Condicionais
- Vetores e Matrizes
- Estrutura de dados (objeto, json, dicionário)
- classes
---
### Habilidades necessárias para qualquer línguagem:

**Lógica de programação** a maneira de pensar de forma lógica colocando no contexto do sistema para resolver problemas;

- Entender regras de negócio, como o sistema funciona.
- Conhecer da sintaxe compartilhada entre as línguagens.
- Entender o fluxo do sistema, por quais arquivos os dados e requisições passam.
- Aprender a ler código gerado por IA.
- Aprender a fazer prompts para IA.
